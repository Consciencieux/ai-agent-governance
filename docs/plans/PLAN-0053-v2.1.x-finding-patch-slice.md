# PLAN-0053：v2.1.x Confirmed Finding 补丁切片

**状态：** Design（2026-09-13；人类选「3」。**不**与 PLAN-0052 并行 Active——施工只走一条 Active；本带在 0052 Archived 或人类改派后才升 Active）。

**归属：** [ADR-0025](../design-decisions/ADR-0025-gen2x-product-path.md) 决策 7 / 8 —— Confirmed Finding 不是一人一个 Horizon；2.x tag 默认不要求清零 Finding。本计划只收 **可交付切片**，目标 SemVer 预期 **patch**（`2.1.x`），由升 Active 时的 Stage 0 再裁决。

**问题（已对齐）：** H2d 已切 FINDING-0003/0007 等，但仍 Confirmed。需要一条不挡 H3、不重开 H2 的补丁施工带。

**不是：** Finding 清零；H3；Gen1 门禁整夹删除（→ 0052）；无切片地把「later」一次做完。

## 一句话目标

从仍 Confirmed 的 Finding 中切出 **一条** 可验证、向后兼容的补丁交付，并写死 In/Out，避免「继续修 Finding」变成无边界扫荡。

## 建议切片（Design 冻结前可改；升 Active 时二选一钉死）

| 候选 | Finding | 建议 In | 明确 Out |
| --- | --- | --- | --- |
| **A（默认推荐）** | [FINDING-0003](../findings/FINDING-0003-declaration-enforcement-gap.md) | 关闭条件 3 余量：对其余 judgment 子句做规范语言分层（mechanical vs judgment），不新造 carrier | 为全部 7 类新写机械 checker；升 MUST 强度 |
| **B** | [FINDING-0007](../findings/FINDING-0007-portability-enforcement-boundary.md) | 矩阵/文档层补强「何为 later、何为 2.1 已交付」；不实现 tool-call hard hook | hooks 必装、`--no-verify` 不可绕过、完整 Runtime Adapter |

默认推荐 **A**：纯规范/载荷文字 + 表征测试，风险低于 runtime。

## 验收面（升 Active 后冻结）

1. 选定候选的 In 条目全部为真；Finding 状态更新诚实（Resolved 仅当关闭条件满足，否则保持 Confirmed 并写清切片进度）
2. `npm run check:must-ship` exit 0
3. CHANGELOG 有类别条目；不偷偷改 CI 阻断权威
4. 硬禁：hooks/L3 非必装；INSTALLED router 仍 REPO-ONLY（无 Narrow ADR 不装）
