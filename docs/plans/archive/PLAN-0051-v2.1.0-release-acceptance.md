# PLAN-0051：v2.1.0 发布验收面（H2 收口后 minor）

**状态：** Archived（2026-09-13；人类「确认」= Approval Gate 批准后完成五同步点 + release commit + tag `v2.1.0`）。Plan archive ≠ Release（产品发布由 tag 完成）。

**归属：** [ADR-0025](../../design-decisions/ADR-0025-gen2x-product-path.md) 决策 8 / 11 —— **SemVer ≠ Horizon**；本计划只写 **`v2.1.0` 验收面与发布序列**，不重开 H2，不开工 H3。

**问题（已对齐）：** H2a–d 施工带已 Archived，但产品仍停在 `2.0.0`；缺一份可执行的 minor 验收声明与 Approval Gate 提案。不得把「H2 做完」直接等同 tag。

**不是：** 把 H3 / L3 / opt-in githooks 钉成 2.1 必装；关闭全部 Confirmed Finding；升 Gen1 `npm run check` 为 CI 阻断；无 Approval Gate 打 tag / push。

## 一句话目标

把 H2 已交付、用户可感知的载荷能力打成 **`v2.1.0` minor**，验收面写死、门禁绿、人类批准后再执行版本五同步点 + tag。

## SemVer 裁决（Stage 0）

| 项 | 裁决 |
| --- | --- |
| 目标版本 | **`2.1.0`（Minor）** |
| 理由 | H2 交付向后兼容、用户/Agent 可感知能力：Git consent 机械 evaluator、原子锁、sibling-closure carrier、MIGRATE 入口、GitLab 多栈残留修复、portability / tool-surface 机读边界 |
| 非 Major | 无对外破坏性公开 API 删除/不兼容 |
| 非 Patch | 不只是文档/内部重构；有可感知行为入口 |
| Out | H3 runtime、hooks/L3 必装、Confirmed Finding 清零 |

## 验收面（In — 必须为真才可 tag）

1. **版本五同步点 + tag** 一致：`package.json` · CHANGELOG `[2.1.0]` · `SKILL.md` · `references/init-spec.json` `governance_version.default` · `scripts/generate-governance.js` 哨兵 · `v2.1.0`
2. **`npm run check:must-ship` exit 0**
3. **`npm run check:skill-release` exit 0**（含 release-gate 文档簇）
4. **工作区干净**；Proposal `headSha` 与即将打 tag 的 HEAD 一致
5. **H2 交付已在 main**（PLAN-0046…0050 Archived；本仓已含 consent/lock/sibling-closure/migrate/portability/tool-surface 表征）
6. **硬禁仍成立**：hooks/L3 ≠ 2.1 必装；Gen1 check 非 CI 阻断；INSTALLED 默认面未装本仓 Task→Capability router（REPO-ONLY proof 仍绿）

## 非验收（显式不挡 2.1）

- H3、CONTROL-X 产品化扩面、完整 Evidence Model
