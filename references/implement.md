# 实现方法

从用户可观察行为找到实际负责模块，读取类型、调用者和相应测试，识别可复用能力。明确验收样例，完成实现及受影响的调用、测试和说明。

用输入、动作与结果表达代码。例如 CSV 导出交给标准库处理逗号、引号和换行；只有一种格式的导出直接实现。真实的多提供方需求可以使用相应接口与适配层。

按 [ENG-03](../shared/standards/engineering.md#eng-03) 处理异常和机制：外部输入在边界验证，内部使用既有不变量；保留有用的失败信息，复用库已有处理。

实现后运行相关验证，回看完整差异和剩余问题。公开用法变化时更新对应说明；普通内部改动不自动产生新的计划、登记表或发行条目。
