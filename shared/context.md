# 上下文与协作

## 保留工作

简单任务使用当前材料与对话。多轮设计、多个已知缺陷或跨会话任务，沿用项目已有计划或工作记录；确需新文件时使用[任务记录片段](../assets/task-state.md)。

保留目标、决定、当前工作、相关文件和尚待处理的已知问题。每个问题记录解决结果或后继位置。来源数据、代码和书目留在原处，工作记录保存定位。

## 刷新时机

- 新任务：读取执行入口及当前动作的材料。
- 转入新模块、出现新操作或新增事实：补读对应标准和有关来源。
- 新会话或上下文压缩后：重读核心、当前入口、工作记录及待处理代码。
- 原文件发生变化：刷新该文件与依赖它的判断。

相同会话中未变化且已完整读取的资源复用。阶段进展按实际结果更新；断点恢复先核对磁盘状态，再继续剩余工作。

## 协作

并行任务按可独立交付的责任分配，约定文件范围、接口与结果。使用宿主或项目既有 worktree、锁及权限方式；单 Agent 工作不创建额外锁协议。

交接说明目标、授权、版本、关键决定、代码与证据位置、已完成和待处理事项。接手者核对共享文件的当前变化。
