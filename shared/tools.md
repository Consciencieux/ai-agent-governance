# 工具使用

## 选择实际命令

从项目入口、包管理配置、锁文件、CI 与已有脚本确定命令。Node、Python、Rust、Go 等项目分别使用自己的工具；禁止因为本 Skill 的构建使用 Python，就把目标项目改成 Python 工作流。

在执行前确认命令、工作目录和输入。重复且复杂的机械操作优先使用成熟工具；确有复用价值的操作可形成短脚本。需要文档、图表、浏览器或其他专项能力时，加载宿主实际提供的技能。

## 搜索与工作区

在目标仓库运行，名称使用固定字符串或适当正则：

```bash
git status --short
git diff --stat
git diff --cached --stat
rg -n --hidden --glob '!.git/**' -F -- '目标名称' .
rg --files --hidden --glob '!.git/**'
```

代码搜索覆盖定义、别名、注册与调用。完整删除时检查属于目标的忽略目录和生成物，可指定目录追加 `--no-ignore`。查看相关二进制、图片和动态生成内容；文本命中用于定位。

`rg` 返回 0 表示命中、1 表示本次无命中、2 表示错误；搜索出错先处理。没有 rg 时使用宿主搜索或 Git 的文本搜索，并补查未跟踪文件与文件名。

## 验证与观察

运行项目的相关测试、静态检查、构建及必要运行示例，检查真实退出码与实际收集的测试。对外分发的包在临时干净目录解包和执行。最终差异可用 `git diff --check` 检查空白问题。

工具提供实际结果，开发与审查依据这些结果作出判断。缺少某项工具时记录具体缺口，完成其余独立工作。构建缓存和测试输出使用项目约定位置；只读审查的有写入副作用验证放在临时副本。
