# 工具使用

## 选择命令

从项目指令、包管理配置、锁文件、CI 和已有脚本取得实际命令。适用的宿主工具、标准库与成熟工具优先；重复复杂操作可用短脚本，一次性调查也可用临时脚本。是否长期维护由复用价值决定。

确认工作目录、输入与操作范围。编写文档、处理图表或查看 UI 时使用实际可用的专项技能。构建缓存、日志与临时文件按项目约定放置。

<a id="search"></a>
## 搜索

从定义、调用和已知影响线索展开。名称可使用固定字符串搜索：

```bash
rg -n --hidden --glob '!.git/**' -F -- '目标名称' .
rg --files --hidden --glob '!.git/**'
```

完整删除再检查属于目标的忽略目录与生成物，按需指定目录及 `--no-ignore`，并查看有关二进制或图件。`rg` 的 0/1/2 分别表示命中、无命中和错误。工具缺席时使用宿主搜索或 Git 搜索，补查未跟踪内容。

<a id="git-diff"></a>
## Git 状态与差异

```bash
git status --short
git diff --stat
git diff --cached --stat
git diff --name-status <base>...HEAD
git diff --name-only --diff-filter=A <base>...HEAD
```

`<base>` 使用该任务或 PR 的真实基线。`--name-status` 区分新增、修改、删除与重命名；统计新增时按 `A` 筛选。PR 三点比较从共同祖先开始，两个快照比较使用两个实际提交。工作区审查另取暂存、未暂存及相关未跟踪内容。

暂存方式按 [PERM-03](standards/permissions.md#perm-03) 选择；最终检查可使用 `git diff --check` 核对空白问题。

## 验证工具

按 [验证标准](standards/verification.md) 运行有关测试和命令，检查退出码、失败、跳过与实际用例。只读审查中会修改文件或产生输出的验证放在临时副本；有外部副作用的命令仍需相应授权。

结构、同步和扫描采用现有工具及 CI；需要自动拦截时配置实际 hook、平台必需检查或宿主权限。语义和架构由审查作判断，用实际任务结果评估效果。
