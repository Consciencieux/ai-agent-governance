# 项目接入与治理巡检

## 识别现有入口

读取当前指令、实际命令、目录与必要配置，确认所用客户端及安装位置。先从宿主可用技能列表核对三个 Skill。项目路径使用真实安装位置。

持久接入请求将[项目指令片段](../../../assets/project-instructions.md)合并进客户端实际读取的入口，保留项目有效要求与命令。日常开发可以直接使用已安装技能。

## 按需求接入

沿用已有架构、用法和任务记录。缺少理解所必需的内容时补对应说明；CI、扫描、分支保护和并行设施各按项目需求启用，优先采用宿主与平台已有工具。

多宿主使用同一份规则来源；各入口只保留必要的触发和引用。安装后确认目录发现，再观察一次只读调用的实际读取；需要验证开发路径时在临时副本中完成小任务。

## 巡检

按本次请求核对发现路径、适用材料、命令与当前事实。只读巡检报告具体不一致；授权修复时修改来源及依赖，再验证改变的路径。重复巡检复用未变化的有效结果。
