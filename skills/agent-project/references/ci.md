# CI 方法

读取实际平台、包管理器、锁文件、测试和构建入口。以现有本地命令形成 CI，按项目支持的运行时和操作系统选择矩阵。

为真实任务配置依赖安装、检查、测试、构建及产物上传。纯文档或没有编译步骤的项目采用自己的验证命令。禁止填入项目不存在的 npm、构建、类型检查或发布命令。

使用平台所需的最小权限，凭据通过受控秘密传递。处理外部贡献时保留平台的信任边界。根据实际依赖采用缓存和必要的触发路径。

先核对命令与工作目录，再通过平台运行验证语法、权限与产物。修改测试发现、路径筛选或 job 条件时，确认有关变更确实会触发对应检查。需要阻止合并的检查，在用户授权下配置分支或规则集要求。
