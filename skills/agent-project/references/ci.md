# CI 方法

读取实际平台、包管理配置、锁文件和测试入口。按用户目标选择要运行的已有命令；只要求 unittest 的项目直接运行 unittest。

依赖安装、格式/类型检查、构建、矩阵、缓存与产物上传各按真实用途配置。禁止为凑齐流水线而加入项目不存在或任务不需要的步骤。已有本地脚本适用时直接复用。

按触发来源设置最小权限，凭据使用平台秘密管理，外部贡献保留不可信代码边界。修改路径筛选、job 条件或测试发现时，核对源码、测试和相关配置变更能触发必要检查；必需检查与过滤策略相互匹配。

先核对本地命令与工作目录并验证配置。具有推送或运行授权时观察平台执行；仅编辑工作流的请求交付文件及已完成验证。需要阻止合并时，按授权配置平台必需检查。
