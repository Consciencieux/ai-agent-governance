# 软件审查

审查实际代码、需求和结果，交付可定位、可执行的判断。只读请求保持工作区不变。

## 加载与范围

读取[工程核心](../../shared/core.md)、[审查方法](references/review.md)、[工程判断](../../shared/standards/engineering.md)与[验证标准](../../shared/standards/verification.md)。按对象共同选取：

| 审查对象 | 材料 |
| --- | --- |
| 变更影响、根因、同类实例、重构和删除 | [变更完整性](../../shared/standards/changes.md) |
| 文档、当前事实、设计记录及计划漂移 | [知识维护](../../shared/standards/knowledge.md) |
| 操作权限、Git 或发布授权 | [授权与 Git](../../shared/standards/permissions.md) |
| 认证、输入、密钥、依赖与外部执行 | [安全标准](../../shared/standards/security.md) |
| 大范围分批读取或恢复 | [上下文与交接](../../shared/context.md) |
| 命令与隔离验证 | [工具使用](../../shared/tools.md) |

当前改动读取暂存、未暂存、未跟踪文件及关联实现；PR 按实际基线和 head；指定目录按该目录及必要依赖；全仓审查列出实际源码范围。深度与范围分别按用户请求确定。读取截断时接续。

## 判定与交付

回读相关原文并验证问题。每项确认问题说明位置、触发条件、实际影响及推荐处理；同一根因合并关联位置。架构问题可以建议重组、替换或删除，普通表达问题给出直接修改意见。

严重级别按真实影响区分：阻止交付的正确性、安全或数据问题；需要修正的实现、结构与文档问题；可选改善。没有依据的问题不进入报告。

只读任务以报告结束。有写入副作用的验证在临时副本运行。用户已要求修复时，读取[日常开发入口](../../SKILL.md)，按原授权实施并复核受影响行为。
