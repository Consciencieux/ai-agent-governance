# 软件审查

审查用户指定对象，交付可定位的判断。只读请求保持源文件与用户工作不变。

## 加载与范围

读取[工程核心](../../shared/core.md)、[审查方法](references/review.md)与项目相关约定。按对象叠加：

| 对象 | 读取材料 |
| --- | --- |
| 代码、设计、根因或架构重评 | [工程判断](../../shared/standards/engineering.md)；重评重点核对 [ENG-05](../../shared/standards/engineering.md#eng-05) |
| 影响范围、同类实例、移动或删除 | [变更完整性](../../shared/standards/changes.md)，删除核对 [CHG-03](../../shared/standards/changes.md#chg-03) |
| 测试、构建、生成、安装或运行结果 | [验证标准](../../shared/standards/verification.md) |
| 文档、来源关系、计划与当前状态 | [知识维护](../../shared/standards/knowledge.md) |
| 操作权限或 Git | [授权与 Git](../../shared/standards/permissions.md) |
| 认证、凭据、不可信输入或外部执行 | [安全标准](../../shared/standards/security.md) |
| 分批读取、恢复或协作 | [上下文与交接](../../shared/context.md) |
| 搜索、差异和隔离验证 | [工具使用](../../shared/tools.md) |

当前改动包括相关暂存、未暂存和未跟踪内容；PR 使用其实际基线与 head；目录审查包含必要依赖。深度与范围分别按请求确定。整文件链接读全文，章节链接读完整目标规则；截断接续，未变材料复用。

## 判定与交付

理解契约与结构，检查实际行为，再核对测试及维护关系。每项确认问题写明位置、触发条件、影响和处理；同一根因合并关联位置。架构错误优先给整体处置，正确代码直接通过。

严重程度按交付阻塞、需要修正、可选改善区分。临时实验与有写入副作用的测试在隔离目录执行；诊断工具选择和范围按实际风险决定。

只读任务以报告结束。用户已要求修复时，读取[日常开发入口](../../SKILL.md)，沿原授权修改并验证。
